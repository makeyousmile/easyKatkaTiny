# easyKatka (easyKatkaTiny)

**easyKatka** — это автономный Telegram-бот и сервис фонового мониторинга матчей в **Dota 2** на базе данных **OpenDota API**.

Бот автоматически отслеживает игры заданной группы игроков (друзей, стака, команды), отправляет красочные визуальные карточки результатов с детальной игровой статистикой, отображает серии побед/поражений (стрики), строит общий рейтинг винрейта и анализирует матчи с помощью **алгоритма детекции руинеров (Ruin Detection)**.

---

## 🌟 Ключевые возможности

### 1. 🎨 Генерация графических карточек матчей (Match Cards)
Вместо скучных текстовых сообщений бот генерирует качественные PNG-изображения (1200×520 px) "на лету" в оперативной памяти:
* **Динамические цветовые темы:**
  * Победа — глубокий бирюзово-изумрудный градиент с неоновым свечением.
  * Поражение — стильный темно-бордовый градиент.
* **Портрет героя:** Локальные текстуры высокого разрешения для всех героев Dota 2 (включая Kez, Ringmaster, Muerta и др.) с автоматическим fallback на Valve/Steam CDN.
* **Профиль игрока:** Аватар Steam, никнейм, значок победы/поражения, длительность матча и время завершения.
* **Серии побед и поражений (Стрики):** Бейджи винстриков (🔥 ВИНСТРИК) и лузстриков (🧊📉 ЛУЗСТРИК) прямо на карточке.
* **Игровая статистика:** KDA, урон по героям (Hero Damage), золото в минуту (GPM), опыт в минуту (XPM), общая ценность (Net Worth), добитые крипы (Last Hits).
* **Инвентарь героя:** Сетка предметов игрока (6 основных слотов, нейтральный артефакт, рюкзак).
* **Бейдж статуса руинера:** Визуальный индикатор `РУИНЕР` (ярко-красный) или `ПОДОЗРЕНИЕ` (оранжевый), если игрок саботировал игру.

### 2. 🚨 Алгоритм детекции руинеров (Ruin Detection System)
Многофакторная скоринговая модель оценивает качество игры и поведение **всех 10 участников матча** (как союзников, так и противников) по шкале **Ruin Score от 0 до 100**:
* **Проверка всех игроков матча:** При завершении игры или вызове `/stat` анализируются все 10 слотов. Если в игре был руинер (в вашей команде или команде врага), бот явно указывает сторону нарушителя (`[Союзник]`, `[Противник]`, `[Игрок (Вы)]`), героя, никнейм и точные причины.
* **Вектор А — Саботаж инвентаря:**
  * Покупка тролль-билдов (3+ или 4+ сапог).
  * Покупка `Shadow Amulet` при нулевой активности и отсутствии урона (< 1500 за 20+ мин) для стояния в AFK-невидимке.
  * Продажа или уничтожение ключевых слотов в поздней игре (пустой инвентарь или одни расходники на 25+ минуте при падении нетворса).
* **Вектор Б — Статистические аномалии и роли:**
  * Катастрофически низкий урон по героям (< 1500 за 20+ минут матча).
  * Критически низкий темп фарма (GPM < 160–220 в зависимости от роли).
  * Умышленный фид: 15+ смертей при крайне низком участии (≤ 3 K+A) либо темп смертей > 0.6 в минуту (смерть каждые 100 секунд).
  * Ливы из матча, отключения и AFK Abandon (`leaver_status >= 2`).
* **Вектор В — Поведение и коммуникация:**
  * Аномальный спам пингов на союзников (≥ 60 пингов за игру).
* **Контекстный учет (Win Mitigation):**
  * Если команда одержала победу без лива, итоговый балл снижается на **25–30%**, предотвращая ложные срабатывания при нестандартных, но успешных сборках.
* **Градации вердикта:**
  * **Ruin Score ≥ 65:** 🚨 **РУИНЕР** (выделение красным, восклицательные знаки и список причин).
  * **Ruin Score 45–64:** ⚠️ **ПОДОЗРЕНИЕ** (предупреждение о подозрительных показателях).
  * **Ruin Score < 45:** Чистая игра.

### 3. 📊 Графическая карточка рейтинга (`/rating`)
* Генерирует стильную PNG-таблицу с рейтингом отслеживаемых игроков по винрейту за последние 50 игр.
* Прогресс-бары побед/поражений, общее число матчей и процент побед.

### 4. 💬 Интерактивные кнопки («Подробнее...»)
* Под каждым уведомлением о матче и карточкой доступна Inline-кнопка **«Подробнее...»**.
* При нажатии бот отображает полный текстовый отчет: урон по вышкам (Tower Damage), лечение союзников (Hero Healing), список названий всех купленных предметов и детальный блок причин детекции руинера.

### 5. 🛡 Отказоустойчивость и независимость от сбоев API
* **Локальные справочники (Zero-Network Startup):** Все 127 героев и 501 предмет Dota 2 вшиты напрямую в бинарник через `//go:embed`. Бот стартует за 0.01 секунды и никогда не падает при старте, даже если OpenDota API лежит.
* **Таймауты и защита от зависаний:** Сетевой таймаут снижен до 10 секунд; при недоступности OpenDota команды пользователя не зависают, а выводят вежливые предупреждения.
* **Резервный демонстрационный режим `/test`:** При падении внешнего API команда `/test` не падает с ошибкой, а отправляет эталонную тестовую карточку с демонстрацией работы алгоритма руинеров.

## 🤖 Команды Telegram-бота

| Команда | Описание |
| :--- | :--- |
| `/stat` | Выводит графические карточки последних сыгранных матчей для каждого отслеживаемого игрока с текущими винрейтами и статусом руинера. |
| `/rating` | Отправляет визуальную инфографику с рейтингом игроков по винрейту (за последние 50 игр). |
| `/friends [N]` | Анализирует совместные матчи и находит лучших напарников по винрейту (по умолчанию за 20 игр, либо за указанное число `N`). |
| `/test` | Генерирует тестовую карточку матча и проверяет отправку уведомления (работает всегда, даже при сбоях внешнего API). |
| `/chatid` | Возвращает Chat ID текущего диалога или группы (удобно для настройки `.env`). |
| `/version` | Показывает текущую версию бота и список изменений (changelog). |
| `/reload` | Перечитывает файл `account_id` «на лету» без перезапуска контейнера. |

## 🏗 Архитектура и стек технологий

```
┌────────────────────────────────────────────────────────┐
│                     Telegram Bot                       │
│          (Long-polling / HTML parse / Keyboards)       │
└───────────────────────────▲────────────────────────────┘
                            │
┌───────────────────────────┴────────────────────────────┐
│                    easyKatka Core                      │
│                                                        │
│  ┌───────────────────┐        ┌─────────────────────┐  │
│  │ Match Monitor     │        │ Ruin Detector       │  │
│  │ (background poll) │        │ (0-100 score model) │  │
│  └─────────┬─────────┘        └──────────▲──────────┘  │
│            │                             │             │
│  ┌─────────▼─────────┐        ┌──────────┴──────────┐  │
│  │ OpenDota Client   │        │ Card Graphics Engine│  │
│  │ (cached, fallbacks│◄───────┤ (fogleman/gg canvas)│  │
│  └─────────┬─────────┘        └──────────┬──────────┘  │
│            │                             │             │
│  ┌─────────▼─────────┐        ┌──────────▼──────────┐  │
│  │ Embedded Assets   │        │ Local Hero Images   │  │
│  │ (heroes & items)  │        │ (125+ PNG assets)   │  │
│  └───────────────────┘        └─────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

* **Язык разработки:** Go 1.26+ (чистый Go, `CGO_ENABLED=0`, vendored dependencies).
* **Сетевое взаимодействие:** Чистый `net/http` стандартной библиотеки Go без внешних утилит (`curl` не используется, загрузка картинок идет через in-memory `multipart/form-data`).
* **Графика и рендеринг:** `github.com/fogleman/gg`, `golang.org/x/image`, `github.com/golang/freetype`. Шрифты DejaVuSans вшиты в бинарник (`assets/fonts`).
* **Контейнеризация:** Легковесный Docker-образ на базе `alpine:3.19` (размер ~25 МБ).

## 🚀 Установка и запуск

### 1. Подготовка конфигурации

1. Склонируйте репозиторий:
   ```bash
   git clone <repo_url>
   cd easyKatkaTiny
   ```
2. Создайте файл `.env` на основе `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Заполните параметры:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ  # Токен от @BotFather
   TELEGRAM_NOTIFY_CHAT_ID=-1001234567890                  # Chat ID для автоматических оповещений
   ```
3. Укажите аккаунты для мониторинга в файле `account_id` (по одному ID на строку). Поддерживаются как 64-битные Steam ID (`76561198...`), так и 32-битные Dota 2 Account ID (`86760227`):
   ```text
   76561198047025955
   76561198032850066
   ```

### 2. Запуск через Docker Compose (Рекомендуется)

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f
```

Остановка контейнера:
```bash
docker compose down
```

### 3. Автоматическая установка через скрипты

* **Ubuntu / Debian:**
  ```bash
  chmod +x ./install-ubuntu.sh
  ./install-ubuntu.sh
  ```
* **Windows (PowerShell):**
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
  ```

### 4. Локальный запуск без Docker (для разработки)

```bash
go test ./...            # Запуск всех 40+ юнит-тестов
go run ./cmd/easykatka   # Запуск приложения локально
```

## 🧪 Тестирование

Проект покрыт подробными юнит-тестами, проверяющими:
* Корректность рендеринга карточек в PNG без утечек памяти.
* Работу алгоритма руинеров во всех граничных случаях (чистый игрок, намеренный фидер, AFK с Shadow Amulet, тролль-билды с сапогами, продажа вещей, лив из игры).
* Обработку команд Telegram и парсинг callback-запросов.
* Расчет винрейтов и серий побед/поражений.

Запуск тестов:
```bash
go test -v ./...
```
